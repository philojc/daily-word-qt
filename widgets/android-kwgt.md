# 매일 말씀 갤럭시 KWGT 시범 위젯

데이터 주소: https://raw.githubusercontent.com/philojc/daily-word-qt/main/data/widget.json

텍스트 3개에 각각 title, book_passage, excerpt를 JSON으로 표시합니다. KWGT Web Get 식은 `$wg("URL", json, .title)$`처럼 구성할 수 있습니다.

전체 위젯 터치 동작을 Launch URL로 지정합니다: https://docs.google.com/document/d/1xi7AyN0haCf1K8uw1VBM4ZBBr0Gs6KINXd9yvqss4WI/edit

현재 위젯은 INT-001 제목과 핵심 구절만 미리보기로 공개하고, 원고 전문은 기존 Google Docs 접근 권한이 있는 사용자만 열 수 있으며, 갱신 지연은 KWGT 및 Android 배터리 설정에 영향을 받습니다.
