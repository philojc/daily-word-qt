# 매일 말씀 | 이름만으로 읽기 진도 동기화 — 쉬운 설치

이전 링크의 읽기 기록용 Google Sheet는 **열지 않으셔도 됩니다**.
설치된 Apps Script가 처음 사용될 때 **스크립트를 배포한 Google 계정에 새 비공개 Sheet를 자동으로 생성**합니다.

## 사용자에게 필요한 최초 1회 작업

1. 지금 사용 중인 Google 계정으로 **[새 Apps Script 프로젝트](https://script.google.com/home/projects/create)**를 엽니다.
2. 왼쪽 `Code.gs` 내용을 모두 지우고 **[매일 말씀 서버 코드 (Code.gs)](./Code.gs)** 전체를 복사해 붙여넣습니다. 저장합니다.
3. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**을 선택하고
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (로그인 필요 없는 배포)
4. 권한을 승인하고 배포한 뒤 **`/exec`로 끝나는 웹 앱 주소**를 복사합니다.
5. 주소를 ChatGPT에 전달하면 공개 웹앱의 `sync-config.js`에 연결할 수 있습니다. 이름이나 읽기 기록을 ChatGPT에 제공할 필요는 없습니다.
6. [매일 말씀 웹앱](https://philojc.github.io/daily-word-qt/) → **내 기록**에서 이름을 입력합니다. 최초 사용자는 **새 이름 등록**, 다른 기기는 **기존 이름으로 이어 읽기**를 선택합니다.

참고: 이전 방식과 달리 Google Sheets 파일을 수동으로 만들거나 열 필요가 없고, `Bridge.html` 파일도 별도로 만들 필요가 없습니다. **Code.gs 하나만** 붙여넣으면 됩니다.

## 작동 원리

- 이름의 공백·대소문자·한글 유니코드 표기를 정규화하여 중복 등록을 검사합니다.
- 사용자별로 5개 트랙 마지막 열람, 읽음 표시, 즐겨찾기를 저장합니다.
- 첫 접속 시 자동 생성되는 Sheet 이름: **매일 말씀 | 개인별 성경 읽기 기록 (자동 생성)**
- 시트 ID는 해당 Apps Script의 `ScriptProperties`에 기록해 이후에도 같은 시트를 사용합니다.
- 서버 주소를 웹앱에 연결하기 전에는 기존처럼 브라우저 기기 내부에만 저장합니다.

## 보안 및 검증

- **이름은 인증수단이 아닙니다.** 이름을 아는 사람이 그 진도를 조회하거나 수정할 수 있습니다.
- 본문 묵상 진행과 즐겨찾기만 저장하고, 개인 기도/상담 기록은 저장하지 않는 것이 좋습니다.
- 이 스크립트 코드는 GitHub에 공개되지만, **자동 생성되는 Sheet 파일은 공개 공유하지 마세요.**
- 코드의 저장소 자동 생성 및 이름별 격리 동작은 모의 테스트를 통과했습니다. **실제 Apps Script 배포와 휴대폰 2대 교차 테스트는 아직 완료되지 않았습니다.**
- Apps Script HTML iframe 접근 정책이나 브라우저 제한에 따라 처음 모바일 테스트에서 추가 조정이 필요할 수 있습니다.

기존의 접근 불가능한 시트는 더 이상 참조하지 않으며 삭제하거나 변경하지 않습니다.
