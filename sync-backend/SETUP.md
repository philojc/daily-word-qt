# 매일 말씀 · 이름 + 개인 코드 읽기 기록 동기화 (1회 설정)

## 현재 상태
- 개인 기록용 **비공개 Google Sheets** 생성 완료: https://docs.google.com/spreadsheets/d/1E9j-c_wyTlv-FTPPOEKtSeTK-w9L2srQ5MvISIb_oH8/edit
- Apps Script 서버 코드: `sync-backend/Code.gs`
- 브라우저 연결 파일: `sync-backend/Bridge.html`
- 웹앱: `sync-client.js` / `sync-config.js`
- 아직 Apps Script 서버를 사용자 Google 계정에서 **배포하지 않았으므로** 실제 기기간 동기화는 비활성화되어 있습니다.
- 기존 브라우저 로컬 읽기 기록은 그대로 유지됩니다.

## 한 번만 설정
1. 개인 기록용 Google Sheet를 열고 **확장 프로그램 > Apps Script**로 이동합니다.
2. `Code.gs` 편집기 내용을 **이 저장소의 `sync-backend/Code.gs` 코드로 교체**하고 저장합니다.
3. Apps Script 왼쪽의 **+ > HTML**을 선택해 파일 이름을 `Bridge`로 만듭니다. `sync-backend/Bridge.html`의 내용을 붙여넣고 저장합니다.
4. 오른쪽 상단 **배포 > 새 배포 > 웹 앱**에서 **실행 사용자: 나**, **액세스 권한: 모든 사용자(Anyone)**를 선택하고 배포합니다. 요청되는 Google 권한은 본인의 개인 기록용 시트에 접근하기 위한 것입니다.
5. 생성된 `https://script.google.com/macros/s/.../exec` 주소를 복사합니다. `/dev` 주소는 외부 사용자가 볼 수 없는 테스트 주소이므로 사용하지 않습니다.
6. GitHub에서 `sync-config.js`를 열어 `window.DW_SYNC_ENDPOINT = "";`의 따옴표 안에 **위 /exec 주소**를 넣고 Commit changes 합니다. GitHub Pages가 자동 재배포되면 준비 완료입니다.
7. 매일 말씀 앱의 **내 기록 > 다른 기기에서도 이어 읽기**에서 이름을 입력하고 **안전한 개인 코드 자동 만들기 → 새 동기화 기록 만들기**를 누릅니다. 코드는 비밀번호 관리자 또는 안전한 장소에 저장해 두세요.
8. 다른 휴대폰에서는 **같은 이름과 같은 코드**로 **기존 기록 불러오기**를 누릅니다. 이 기기에 새로운 개인 프로필이 만들어져 동기화됩니다.

## 동작
- 한 사람마다 각자 이름·코드 조합으로 기록을 식별합니다.
- 기록은 공개 원고가 아닌 별도 비공개 Google Sheet에 들어갑니다.
- 전송 데이터는 읽음/즐겨찾기/마지막 읽은 회차/트랙별 마지막 회차뿐입니다.
- 기기 A에서 읽음 표시한 뒤 연결에 성공하면, 기기 B에서 서버에서 다시 불러오거나 새로 접속할 때 반영됩니다.
- 앱 내 프로필은 동일 브라우저 사용자 편의 기능이지 비밀번호로 보호되는 로그인 계정은 아닙니다.
- 코드를 같은 기기에 기억시키면 브라우저 localStorage에 코드가 저장됩니다. **공유 기기에서는 연결 해제**를 사용하고, 다른 사람의 코드가 노출되지 않도록 주의하세요.
- 코드 분실 시 본인 증명으로 복구할 방법이 없습니다. 이름은 비밀번호가 아닙니다.
- 원고는 공개되어 있지만 개인 읽기 기록은 비공개로 운영됩니다.

## 주의·한계
- 서버 배포와 실제 2기기 교차 테스트 **미완료**입니다. 특히 Google Apps Script iframe 연결은 브라우저의 차단 정책·Google 변경에 영향을 받을 수 있어 실제 아이폰/안드로이드 테스트가 필요합니다.
- 간단한 가족용입니다. 금융·의료 정보·민감한 기도 기록 등은 저장하지 마세요. 단순한 코드 인증은 정식 OAuth·비밀번호 기반 인증과 동일한 보안 수준이 아닙니다.
- 코드는 20자리 랜덤 코드를 권장합니다. 4~6자리나 생일·전화번호 등의 추측 가능한 코드는 허용하지 않습니다.
- 동기화 코드가 아직 연결되지 않았을 때는 기존 로컬 저장, 읽음 표시, 파일 내보내기/가져오기만 동작합니다.
- 기존 로컬 프로필에서 원격 동기화 계정으로 **기록 자동 병합은 아직 제공하지 않습니다.** 기록을 옮기려면 추가 이관 기능을 만들어야 합니다.
