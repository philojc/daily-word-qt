# 매일 말씀 | 이름만으로 읽기 기록 동기화 · 최소 권한 버전

## 안전 변경 (2026-10-26)
기존 Apps Script는 Google Sheets 파일을 자동 생성하기 위해 **모든 스프레드시트의 조회/수정/삭제 권한**을 요청했습니다.
하지만 가족 두 사람이 읽기 진도만 보관하는 목적에는 지나친 권한이므로 **Google Sheets 의존성을 제거했습니다**.

이제 `Code.gs` 한 파일에서 **PropertiesService (스크립트 내부 저장소)** 를 사용합니다. 기존 Google Sheets 링크는 열 필요가 없습니다.
기존 코드에 대해 뜬 'Google hasn't verified this app' 승인 화면에서 **Back to safety**로 돌아가고 아래 새 코드로 교체하세요.

## 수정된 코드 적용하기 (이미 Apps Script 프로젝트를 만들었다면)
1. 본인의 Apps Script 프로젝트 편집 화면으로 돌아갑니다.
2. `Code.gs`의 **기존 전체 코드를 지우고**, [업데이트된 Code.gs](./Code.gs)의 내용을 **전체 붙여넣기** 후 저장합니다.
3. Apps Script 편집기의 **개요 → 프로젝트 OAuth 범위**에 불필요한 스프레드시트 권한이 남아 있는지 확인합니다. 기존 프로젝트가 이전 권한을 계속 표시할 경우 **새 Apps Script 프로젝트**에 이 새 코드만 붙여 넣어 진행합니다.
4. **배포 → 새 배포 → 웹 앱**: 실행 사용자 `나`, 접근 `모든 사용자`를 선택합니다.
5. 배포 완료 후 `https://script.google.com/macros/s/.../exec` 웹 앱 URL을 복사해 ChatGPT에 알려 주세요.

기존에 이미 배포했다면 **배포 관리 → 수정 → 새 버전 배포**를 해야 수정된 코드가 적용됩니다. 처음부터 간단하게 새 배포를 만들어도 됩니다.

## 사용 방식
- 서로 다른 사람은 각자 이름 하나씩 등록합니다. 새 이름을 등록할 때 이미 사용 중이면 거절합니다.
- 다른 기기에서 같은 이름을 입력하면 해당 이름으로 읽던 기록을 불러옵니다.
- 5개 트랙의 최근 본문, 읽음 표시, 즐겨찾기를 따로 저장합니다.
- **이름은 인증이 아닙니다.** 이름만 알면 다른 사람도 해당 기록을 읽거나 바꿀 수 있습니다.

## 기술적 제한
- ScriptProperties는 **값 하나당 9 KB, 스크립트 저장소 전체 500 KB** 한도를 가집니다.
- 기록은 사용자별 여러 조각으로 분할 저장하며, 최대 가족 30명 / 한 사람 기록 최대 15조각으로 제한합니다. 실사용 범위에서 용량에 접근하면 데이터 이관이 필요합니다.
- 구글 계정의 모든 스프레드시트 접근권한은 새 코드에서는 필요하지 않습니다. 이전 프로젝트에 자동 설정된 OAuth 범위가 있다면 업데이트 후 직접 점검하세요.
- 실제 Google Apps Script 배포와 아이폰/갤럭시 브라우저에서의 교차 기기 동기화는 아직 검증하지 않았습니다.
