# 매일 말씀 | 이름 하나로 진도 이어 읽기

## 현재 상태
- 웹앱 UI와 Google Sheets/Apps Script 연동 코드를 이름만 사용하는 방식으로 변경했습니다.
- 개인 기록용 시트: https://docs.google.com/spreadsheets/d/1E9j-c_wyTlv-FTPPOEKtSeTK-w9L2srQ5MvISIb_oH8/edit
- **서버를 실제로 배포한 것은 아닙니다.** 동기화를 사용하려면 최초 한 번의 Apps Script 설정이 필요합니다.
- 현재 웹앱의 읽음 기록과 내보내기 기능은 설정 전에도 기존처럼 사용할 수 있습니다.

## 최초 1회 설정 (Google 계정 소유자가 진행)
1. 위 개인 기록용 Google Sheet를 열고 **확장 프로그램 → Apps Script**를 클릭합니다.
2. 기본 `Code.gs`의 내용을 전부 지운 다음 [Code.gs](./Code.gs) **파일 하나만** 붙여넣고 저장합니다. HTML 파일을 별도로 만들 필요가 없습니다.
3. **배포 → 새 배포 → 웹 앱**에서 실행 사용자는 `나`, 접근 권한은 `모든 사용자`로 선택합니다. 이 방법은 로그인 없는 접속을 위해 필요합니다.
4. 사용 권한 승인 후 표시되는 `https://script.google.com/macros/s/.../exec` 주소를 복사합니다. **개인 이름은 전달할 필요가 없습니다.**
5. GitHub [sync-config.js](../sync-config.js)의 `window.DW_SYNC_ENDPOINT = "";` 따옴표에 위 URL을 붙여넣고 저장합니다. GitHub Pages가 다시 배포됩니다.
6. 웹앱 [매일 말씀](https://philojc.github.io/daily-word-qt/)의 **내 기록**에서 이름을 입력한 뒤, 새 사용자면 **새 이름 등록**, 기존 사용자면 **기존 이름으로 이어 읽기**를 선택합니다.

## 사용 방식
- 같은 이름으로 새로 등록할 때 서버가 **대소문자/공백/한글 정규화를 반영하여 중복을 확인**하고 거절합니다.
- 이미 등록된 이름은 '기존 이름으로 이어 읽기'를 눌러 해당 진행 기록을 불러옵니다.
- 개인별 5개 트랙 최근 회차, 완료 표시, 즐겨찾기를 서버에 따로 기록합니다. 변경사항은 인터넷 연결 시 전송합니다.
- 다른 기기에서 동일한 이름으로 연결할 수 있으며, 열린 웹앱으로 돌아왔을 때 서버 기록을 다시 조회합니다.

## 매우 중요한 제한
- 이름을 안다고 해서 그 사람이 본인이라는 보장은 없습니다. **그 이름을 아는 사람 누구나 동일한 기록을 읽고 바꿀 수 있습니다.**
- 이름 중복 검사는 '같은 이름의 기록 두 개가 생기는 문제'만 막습니다. 계정 보호나 비밀번호가 아닙니다.
- 기도 내용, 영적 상담, 개인정보 등 민감한 기록은 이 저장소에 저장하지 않습니다.
- 악의적인 사람이 이름을 선점하거나 내용을 수정하는 것을 막을 수 없습니다. 가족용 비민감 독서 진도에만 권장합니다.
- 설정 후에도 Apps Script HTML iframe의 접속이 모바일 브라우저에서 정상 작동하는지 실기기 교차 검증해야 합니다.
